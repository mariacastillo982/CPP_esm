# Biological Ontology Construction from Literature                                                                                                                                                                                                   
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
This project implements a pipeline to construct a biological ontology from scientific literature (PubMed abstracts) using Large Language Models (LLMs). It focuses on Cell-Penetrating Peptides (CPPs), their mechanisms, molecular players, cargo,  
and subcellular targets.                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
## Project Workflow                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
1.  **Literature Retrieval**: Fetches relevant PubMed abstracts based on a keyword.                                                                                                                                                                  
                                                                                                                                                                                                                                                     
2.  **Text Preprocessing**: Cleans and splits abstracts into sentences.                                                                                                                                                                              
                                                                                                                                                                                                                                                     
3.  **LLM Extraction**: Uses an LLM (e.g., OpenAI's GPT models) to extract entities and relationships as structured triples (subject, predicate, object) from the text.                                                                              
                                                                                                                                                                                                                                                     
4.  **Ontology Construction**: Populates an ontology (using `owlready2`) with defined classes and properties based on the extracted triples.                                                                                                         
                                                                                                                                                                                                                                                     
5.  **Export Ontology**: Saves the constructed ontology as an OWL file.                                                                                                                                                                              
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
## Prerequisites

This is **highly recommended** by NCBI to avoid potential IP blocking for excessive anonymous queries.

    Example for Linux/macOS (in your shell configuration file like `.bashrc` or `.zshrc`):                                                                                                                                                           
                                                                                                                                                                                                                                                     
    ```bash                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                     
    export OPENAI_API_KEY="your_openai_api_key"                                                                                                                                                                                                      
                                                                                                                                                                                                                                                     
    export ENTREZ_EMAIL="your_email@example.com"

## Usage                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
The main script to run the pipeline is `main.py`. It accepts several command-line arguments.                                                                                                                                                         
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
**Command:**                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                     


python main.py  [options]                                                                                                                                                                                                                            

                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
**Arguments:**                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
*   `<keyword>` (required): The keyword to search PubMed (e.g., "cell-penetrating peptides", "Tat peptide mechanism"). Enclose in quotes if it contains spaces.                                                                                      
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
**Options:**                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
*   `--max_articles_fetch INT`: Maximum number of PubMed articles to fetch initially.                                                                                                                                                                
                                                                                                                                                                                                                                                     
    *   Default: `50`                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                     
*   `--max_articles_extract INT`: Maximum number of fetched articles to process for LLM extraction. This helps manage cost and processing time.                                                                                                      
                                                                                                                                                                                                                                                     
    *   Default: `10`                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                     
*   `--openai_model STR`: OpenAI model to use for extraction (e.g., "gpt-3.5-turbo", "gpt-4", "gpt-4-turbo").                                                                                                                                        
                                                                                                                                                                                                                                                     
    *   Default: `"gpt-3.5-turbo"`                                                                                                                                                                                                                   
                                                                                                                                                                                                                                                     
*   `--output_owl_file STR`: Filename for the output OWL ontology.                                                                                                                                                                                   
                                                                                                                                                                                                                                                     
    *   Default: `"cpp_ontology.owl"`                                                                                                                                                                                                                
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
**Example:**                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
To search for "cell-penetrating peptides", fetch up to 30 articles, process 5 of them using "gpt-3.5-turbo", and save the output to "my_cpp_ontology.owl":                                                                                           
                                                                                                                                                                                                                                                     

python main.py "cell-penetrating peptides" --max_articles_fetch 30 --max_articles_extract 5 --openai_model "gpt-3.5-turbo" --output_owl_file "my_cpp_ontology.owl"                                                                                   

                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
If you only provide the keyword, default values for other options will be used:                                                                                                                                                                      
                                                                                                                                                                                                                                                     

python main.py "Tat peptide"                                                                                                                                                                                                                         

                                                                                                                                                                                                                                                     
This will use the default settings (fetch 50 articles, process 10, use "gpt-3.5-turbo", output to "cpp_ontology.owl").                                                                                                                               
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
## Project Structure                                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
*   `main.py`: Orchestrates the entire pipeline from literature retrieval to ontology export. This is the main entry point.                                                                                                                          
                                                                                                                                                                                                                                                     
*   `fetch_pubmed.py`: Handles querying PubMed and downloading abstracts using `Biopython` (Entrez API).                                                                                                                                             
                                                                                                                                                                                                                                                     
*   `llm_extraction.py`: Contains functions for text preprocessing (using `spacy`) and interacting with the OpenAI API to extract entities and relationships as structured triples.                                                                  
                                                                                                                                                                                                                                                     
*   `ontology_builder.py`: Uses `owlready2` to define the ontology schema (classes, properties), populate it with extracted triples, and save the ontology to an OWL file.                                                                           
                                                                                                                                                                                                                                                     
*   `requirements.txt`: Lists the Python packages required for the project.                                                                                                                                                                          
                                                                                                                                                                                                                                                     
*   `Ontology/` (This directory, if used for ontology-related files)                                                                                                                                                                                 
                                                                                                                                                                                                                                                     
    *   `README2.md`: This file.                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
    *   `create_ontology.py`: (Currently empty, might be intended for specific ontology creation logic or schema definition if separated from `ontology_builder.py`).                                                                                
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
## Output                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
The primary output of the pipeline is an OWL (Web Ontology Language) file (e.g., `cpp_ontology.owl` or the name specified by `--output_owl_file`). This file contains the constructed ontology and can be opened and visualized using ontology       
editors like [Protégé](https://protege.stanford.edu/).                                                                                                                                                                                               
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
The ontology will include:                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                     
*   **Classes**: `CPP`, `UptakeMechanism`, `Cargo`, `MolecularPlayer`, `SubcellularTarget`.                                                                                                                                                          
                                                                                                                                                                                                                                                     
*   **Object Properties (Relationships)**: `usesMechanism`, `delivers`, `involves`, `targets`, `interactsWith`.                                                                                                                                      
                                                                                                                                                                                                                                                     
*   **Data Properties**: `hasGOTerm`, `hasPmid`.                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
*   **Individuals**: Instances of the classes, populated from the literature, along with their relationships.                                                                                                                                        
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
## Troubleshooting                                                                                                                                                                                                                                   
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                     
*   **`OPENAI_API_KEY` not set**: Ensure the environment variable is correctly set and accessible by the Python script.                                                                                                                              
                                                                                                                                                                                                                                                     
*   **`ENTREZ_EMAIL` not set**: While the script might run, NCBI prefers an email for queries. Set this environment variable.                                                                                                                        
                                                                                                                                                                                                                                                     
*   **spaCy model not found**: Make sure you've run `python -m spacy download en_core_web_sm`.                                                                                                                                                       
                                                                                                                                                                                                                                                     
*   **`ModuleNotFoundError`**: Ensure you have activated your virtual environment (if using one) and installed all packages from `requirements.txt`.                                                                                                 
                                                                                                                                                                                                                                                     
*   **LLM Output Issues**: The quality of extracted triples heavily depends on the LLM model and the prompt used in `llm_extraction.py`. The prompt may need refinement for better accuracy or to capture more nuanced information.                  
                                                                                                                                                                                                                                                     
*   **Cost**: Using OpenAI's API, especially with models like GPT-4, can incur costs. Monitor your usage. The `--max_articles_extract` argument can help limit this.
